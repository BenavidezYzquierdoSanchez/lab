01 / PLANTEAMIENTO

Problema, objetivo y fuente de datos

Una pregunta de negocio clara, un conjunto de datos procesado y un análisis descriptivo reproducible.

¿Qué problema investigamos?

Las transacciones digitales generan grandes volúmenes de información. Identificar grupos con mayor incidencia observada de fraude ayuda a priorizar análisis y revisiones sin confundir asociación con causalidad.

¿Cómo varía la incidencia del fraude por horario, bandera de riesgo y otros atributos analíticos?

Objetivo del proyecto

Diseñar, desplegar y verificar un flujo en AWS para ingerir datos, transformarlos, catalogarlos y consultarlos con SQL; presentar indicadores comprensibles, evidencias de ejecución y una revisión separada de los costos.

04 · Cargar y procesar
python scripts/run_aws.py upload --region us-east-1 --data data/real/fraude_tarjeta_credito_process.csv
python scripts/run_aws.py etl --region us-east-1
python scripts/run_aws.py catalog --region us-east-1
05 · Consultar y visualizar
python scripts/run_aws.py queries --region us-east-1

Cómo usar esta presentación

  • Selecciona una sección en el menú lateral.
  • Alterna paleta y modo claro/oscuro desde la barra superior.
  • En «App» cambia métrica, segmento y exporta la tabla.
  • Amplía cualquier captura de la galería con un clic.
  • Pulsa «Presentar» para ocultar el menú; «Pantalla completa» para ocupar toda la pantalla (Shift+F, salir con Esc).
